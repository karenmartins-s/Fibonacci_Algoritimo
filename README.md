# Sequência de Fibonacci em C

## Sobre o projeto

Este projeto foi desenvolvido em linguagem C como exercício de programação, com o objetivo de calcular e exibir os primeiros termos da sequência de Fibonacci.

O programa solicita ao usuário um número `N` e exibe a quantidade de termos da sequência correspondente ao valor informado.

## Como funciona

A sequência de Fibonacci começa com os números `0` e `1`. A partir deles, cada novo termo é calculado somando os dois termos anteriores.

**Exemplo de execução:**

```text
Digite o valor de N: 8

0 1 1 2 3 5 8 13
```

## Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h` para entrada e saída de dados.
- Biblioteca `stdlib.h` incluída no código.

## Conceitos utilizados

- Declaração e inicialização de variáveis.
- Entrada de dados com `scanf()`.
- Exibição de informações com `printf()`.
- Estrutura de repetição `for`.
- Estruturas condicionais `if` e `else`.
- Operações matemáticas e atualização de variáveis.

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `.c` em uma IDE, como o Code::Blocks.
3. Compile e execute o programa.
4. Digite a quantidade de termos que deseja visualizar.

## Objetivo do exercício

Praticar os conceitos básicos de programação em C e desenvolver a lógica necessária para gerar uma sequência numérica utilizando estruturas de repetição.
